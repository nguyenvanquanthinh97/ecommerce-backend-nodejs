## install dependencies
```bash
sudo amazon-linux-extras install epel -y
```

## install mysql
```bash
# Clean the cache
sudo dnf clean all

# Now install MariaDB
sudo dnf install -y mariadb105-server

# Start and enable MariaDB
sudo systemctl start mariadb
sudo systemctl enable mariadb

# Check status
sudo systemctl status mariadb

# Secure the installation
sudo mysql_secure_installation
```

## retrieve mysql password
```bash
1. Enter current password for root (enter for none):
Just press Enter (there's no password yet)

2. Switch to unix_socket authentication [Y/n]:
Press n (this allows you to use password authentication)

3. Change the root password? [Y/n]:
Press Y and set a strong password

4. Remove anonymous users? [Y/n]:
Press Y

5. Disallow root login remotely? [Y/n]:
Press Y (unless you need remote root access)

6. Remove test database and access to it? [Y/n]:
Press Y

7. Reload privilege tables now? [Y/n]:
Press Y
```

## Update user password
```bash
mysql -uroot -p
```

## copy file from local to ec2
```bash
scp -i ~/.ssh/key.pem ~/Downloads/mysqlsampledatabase.sql ec2-user@<public-domain>:~/
```

## import dump data to mysql
```bash
mysql -uroot -p
source mysqlsampledatabase.sql
```

## CREATE USER ACCOUNT
```bash
CREATE USER 'anonystick'@'%' IDENTIFIED WITH mysql_native_password USING PASSWORD('password');
GRANT ALL PRIVELEGES ON <db>.<tables> TO 'anonystick'@'%';
```
